👋 Hi, I'm **Subhankar Roy** — a Full-Stack Developer with a B.Tech in IT and 5+ years of experience building scalable ERP, logistics, eCommerce, and healthcare solutions.

## 🛠️ Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

```bash
npm run build   # production build
npm start       # run the production build
```
